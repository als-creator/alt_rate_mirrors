# Формат: хост|директория дистрибутива|комментарий
# Используется скриптом alt_rate_mirrors.sh (опция --mirrors-file).
# Каждый хост проверяется и по http, и по https (--protocol auto).
#
# Источники списка:
#   * https://www.altlinux.org/Зеркала, https://www.altlinux.org/Releases/Download
#   * apt-check (apt-check-qt, автор Petr-akhlamov)
#   * alt-mirror-switcher (shad)
#
# Проверка активности: bash check_mirrors.sh
# Дата проверки: 2026-09-19. Все хосты ниже отвечают на pkglist
# (Sisyphus и/или p11) по http и https, кроме mirror.mephi.ru —
# у него работает только http (https не отдаёт репозиторий).
#
# Отвергнуто при проверке 2026-09-19 (не отвечают по http/https
# либо не содержат актуальных веток — не включать):
#   mirror.eterfund.org       — мёртв (живой аналог: mirror.eterfund.ru)
#   ftpmirror2.infania.net    — мёртв
#   mirror.hoster.kz          — жива только старая раскладка p8 (x86_64/base)
#   altlinux.tomsk.ru         — теперь городской портал Томска, не зеркало
#   ftp.heanet.ie             — мёртв
#   mirror.corbina.ru         — мёртв
#   mirror.timeweb.ru         — мёртв
#
# Чтобы добавить своё зеркало — допишите строку в конец и
# запустите: bash check_mirrors.sh && bash alt_rate_mirrors.sh --mirrors-file mirrors.txt
