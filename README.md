# alt_rate_mirrors

Аналог **rate-mirrors** (для Arch) для **ALT Linux**: автоматически определяет
ветку дистрибутива, тестирует зеркала репозиториев на скорость и свежесть и
записывает в конфигурацию `apt` самые быстрые и актуальные.

Скрипт не требует установки — запускается одной командой из интернета,
права повышаются через `su` (в ALT по умолчанию нет `sudo`).

---

## Быстрый старт (запуск из интернета)

```bash
curl -fsSL https://raw.githubusercontent.com/als-creator/alt_rate_mirrors/main/alt_rate_mirrors.sh \
  -o /tmp/alt_rate_mirrors.sh && bash /tmp/alt_rate_mirrors.sh
```

Перед записью конфигурации будет запрошен пароль root (через `su`, а если
установлен `sudo` — через него). Старые файлы репозиториев сохраняются в
бэкап, после применения запускается `apt-get update`.

Хотите только посмотреть, что получится, ничего не меняя:

```bash
curl -fsSL https://raw.githubusercontent.com/als-creator/alt_rate_mirrors/main/alt_rate_mirrors.sh \
  -o /tmp/alt_rate_mirrors.sh && bash /tmp/alt_rate_mirrors.sh --dry-run
```

## Поддерживаемые дистрибутивы

Проверка не завязана на название продукта — она читает ветку из системного
макроса `%_priority_distbranch` (файл `/etc/rpm/macros.d/altlinux-release`,
который есть в каждом продукте ALT). Поэтому работают все дистрибутивы
семейства:

- **ALT Linux** — Рабочая станция, Сервер, Образование и др. (платформы p10/p11/p12);
- **Simply Linux** (на платформе, например p11/p12);
- **Регулярные сборки** для энтузиастов (RegularGNOME и др., на Sisyphus или платформе);
- **Стартовый комплект** (Starter Kit) и прочие редакции.

Поддерживаемые ветки: `Sisyphus` (rolling) и стандартные платформы
`p10`/`p11`/`p12`/... Архитектуры: `x86_64`, `i586`, `aarch64` и т.д.
Контроль «чужой версии» работает одинаково для всех: ветка и архитектура
в путях конфига сверяются с системой независимо от названия продукта.

## Как это работает

1. **Определение системы.** Проверяется, что это действительно ALT Linux
   (`/etc/altrelease`, `ID=altlinux` в `/etc/os-release`). Ветка определяется
   через канонический макрос `rpm --eval %_priority_distbranch`
   (`sisyphus`, `p10`, `p11`, `p12`, ...), при его отсутствии — из
   `/etc/altrelease`. Архитектура — через `rpm --eval %_arch`.

   Такое определение исключает путаницу между Sisyphus и стандартными
   платформами: пути репозиториев строятся строго под найденную ветку
   (`Sisyphus/x86_64` против `p11/branch/x86_64`).

2. **Контроль «чужой версии».** Перед тестированием скрипт сверяет пути в
   существующем конфиге с реальной системой: ветка в путях (`Sisyphus`,
   `p11`, ...) должна совпадать с веткой системы, и хотя бы одна секция
   должна соответствовать архитектуре машины. Если конфиг относится к другой
   ветке или архитектуре — скрипт останавливается и **ничего не меняет**
   (выйти из-под защиты можно только явным `--force`). Зеркало другой версии
   применить не получится.

2. **Чтение текущего конфига.** Скрипт берёт секции из
   `/etc/apt/sources.list.d/*.list`, в которых пути ведут в репозитории ALT
   (`Sisyphus/...`, `p11/...`, и т.п.), и **сохраняет их пути и компоненты
   без изменений** — меняется только адрес зеркала. Локальные источники
   (`rpm file://...`) и не-ALT репозитории не трогаются.

3. **Тестирование зеркал.** Список зеркал собран из
   [вики ALT Linux](https://www.altlinux.org/Зеркала), из списка зеркал
   `apt-check` (apt-check-qt) и `alt-mirror-switcher`, и проверен на
   активность (2026-09-19, см. `check_mirrors.sh` — мёртвые зеркала
   в список не включены). Для каждого зеркала:

   - проверяется доступность **всех** секций конфига (архитектура, multilib,
     noarch) по файлу `base/pkglist.classic.xz` — если какой-то секции нет,
     зеркало отбрасывается как неполное;
   - проверяется **свежесть** по дате последнего обновления индекса
     (по умолчанию отбрасываются зеркала старше 72 часов, см.
     `--max-age-hours` и `--allow-stale`);
   - замеряется **скорость** скачиванием того же файла индекса (метод
     `apt-check`: тестируем то, что реально будет качаться при обновлении),
     а также время соединения.

4. **Выбор и применение.** Зеркала ранжируются по скорости (при равной —
     предпочитается HTTPS), в конфиг записываются N лучших (по умолчанию 3),
     для каждого — все секции из текущего конфига. Перед записью делается
     бэкап `/etc/apt/sources.list.d`, после — `apt-get update`.

## Опции

| Опция | Описание | По умолчанию |
|---|---|---|
| `-n, --dry-run` | только тест и показ результата, ничего не писать | выкл. |
| `-t, --top N` | сколько лучших зеркал записать | `3` |
| `--max-time N` | лимит замера скорости одного зеркала, сек | `15` |
| `--max-age-hours N` | зеркала с индексом старше N часов отбрасываются | `72` |
| `--allow-stale` | не отбрасывать старые зеркала (в конце списка) | выкл. |
| `--protocol P` | `auto` (https, если работает), `http`, `https` | `auto` |
| `--parallel N` | параллельных замеров скорости | `6` |
| `--mirrors-file F` | свой список зеркал `хост|директория|комментарий` | встроенный |
| `-f, --force` | не проверять, что система — ALT Linux | выкл. |
| `--no-update` | не запускать `apt-get update` после применения | выкл. |
| `-v, --verbose` | подробный вывод | выкл. |
| `-h, --help` | справка | — |

Примеры:

```bash
# сухой прогон: протестировать и показать новый конфиг
bash alt_rate_mirrors.sh --dry-run

# применить два лучших зеркала
bash alt_rate_mirrors.sh --top 2

# только HTTPS-зеркала
bash alt_rate_mirrors.sh --protocol https

# свой список зеркал
bash alt_rate_mirrors.sh --mirrors-file mirrors.txt
```

## Права root

В ALT Linux по умолчанию нет `sudo`. Порядок повышения прав:

1. если уже запущены от root — пишем напрямую;
2. если установлен `sudo` — используем его;
3. иначе `su - root -c '...'` (запросит пароль root).

## Безопасность и точность

- Репозитории записываются **точно по секциям уже настроенной системы**
  (например, `p11/branch/x86_64 classic gostcrypto` останется как есть) —
  после переключения не бывает «пропавших» репозиториев при обновлении.
- Зеркало без нужной секции (noarch/multilib) в топ не попадает.
- Перед записью создаётся бэкап `/etc/apt/sources.list.d.bak-<дата>`.
- Восстановить из бэкапа:

  ```bash
  su -c "rm -rf /etc/apt/sources.list.d && mv /etc/apt/sources.list.d.bak-20260919-123456 /etc/apt/sources.list.d"
  ```

- Если ни одно зеркало не прошло тесты — конфигурация не изменяется.

- [update_sisyphus_mirrors.sh](https://github.com/als-creator/altlinux_scripts/blob/main/update_sisyphus_mirrors.sh) — скрипт
  переключения зеркал из репо [als-creator/altlinux_scripts](https://github.com/als-creator/altlinux_scripts): адреса
  и формат строк `rpm` для Sisyphus.

Официальный список зеркал в закомментированном виде лежит в самом скрипте
и в файле `mirrors.txt`. Дополнить можно строкой в формате
`хост|директория дистрибутива|комментарий`.

### Проверка активности

Перед включением в список каждое зеркало проверяется скриптом
`check_mirrors.sh`: он читает `mirrors.txt`, для каждого хоста пробует
http и https и ищет живые разделы репозитория (Sisyphus, p10/p11/p12) по
файлу `base/pkglist.classic.xz`. Зеркало считается живым, если отвечает
хотя бы по одному протоколу, а его индексы не старше порога
(`--max-days`, по умолчанию 7):

```bash
bash check_mirrors.sh                 # проверить весь mirrors.txt
bash check_mirrors.sh --max-days 14   # другой порог свежести
```

Последняя проверка — **2026-09-19**: в списке 10 живых зеркал,
`mirror.mephi.ru` работает только по http. Отвергнуты как нерабочие:
`mirror.eterfund.org`, `ftpmirror2.infania.net`, `mirror.hoster.kz`
(осталась лишь старая p8-раскладка), `altlinux.tomsk.ru`, `ftp.heanet.ie`,
`mirror.corbina.ru`, `mirror.timeweb.ru`.
